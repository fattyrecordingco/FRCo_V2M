# V2M Roadmap

## Now (`v0.1.x`)
- Local AI-assisted MIDI ideation.
- Reliable MIDI export.
- Presets and parameter controls.
- Basic usability improvements.

## Next (`v0.2.x`)
- Better arrangement helpers (intro/verse/hook patterns).
- Improved style consistency and variation controls.
- Faster generation and better repeatability options.

## Later (`v0.3.x+`)
- Plugin prototype for DAW workflow.
- Direct drag-and-drop or in-DAW trigger flow.
- Optional cloud-backed model enhancements.

## Risk Management
- Plugin complexity risk: keep plugin effort as a parallel track, not blocking MVP.
- Scope creep risk: prioritize stable core workflow before new feature categories.
- Release quality risk: use a repeatable checklist per version.
